# CMP discovery icon provenance

Owner-supplied Tabula CMP redesign handoff, received 2026-10-08 from
`tabula-cmp-mobile-design`. The handoff records generation with built-in
`image_gen`; the icon is independent of Tabula’s canonical T Portal brand.

`catalog-icon-master.png` preserves the 1254×1254 RGBA source.
The unchanged 256×256 and 512×512 PNG companions are in the parent directory.
The mobile catalog generator copies these discovery-only companions into
Compose file resources; neither the master nor a gameplay pack is loaded
while browsing. Runtime pack manifests and rule/package identities are unchanged.
